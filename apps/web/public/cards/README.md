# Supplied card artwork

These eleven images were supplied by the user on 11 November 2026 and copied unchanged. The latest user request explicitly replaces the earlier SVG-only art direction with these exact card faces and the reference sheet.

Files `spy` through `princess` map to ranks 0–9. `reference.png` is the player reference sheet.

The game displays the source card rectangle using CSS overflow clipping with rounded corners. At 896×1200 the rectangle is x=48, y=44, width=800, height=1120; the two 1792×2400 sources use the doubled rectangle. No generative redraw, artwork replacement, raster manipulation, or text changes are applied. The original files retain their surrounding background; it is excluded from the rendered card in the game.

The card back is an original code-rendered purple/gold design; no back image was supplied. All players' hidden hands use only this shared back.
